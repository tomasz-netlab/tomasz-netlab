## Featured projects

### [Lab 01 — VLAN Segmentation, Inter-VLAN Routing and IOS Hardening](https://github.com/tomasz-netlab/network-lab-vlan-intervlan-routing)

Small enterprise-like network lab built in Cisco Packet Tracer. Covers Layer 2 segmentation, inter-VLAN routing via Router-on-a-Stick, SSH-only management access, IOS device hardening, STP protection with BPDUGuard, and centralized Syslog and NTP.

**Topics:** VLANs · 802.1Q trunking · Router-on-a-Stick · SSH v2 · IOS hardening · PVST+ · BPDUGuard · Syslog · NTP  
**Status:** Published ✅
